# Projeto CRUD de Usuários em MVC

Este é um projeto desenvolvido em PHP utilizando uma arquitetura pura em **MVC (Model-View-Controller)**. O sistema permite **cadastrar, editar, listar e remover usuários**, com persistência em banco de dados e interações dinâmicas via **JavaScript, jQuery e Ajax**.

## 🛠 Tecnologias Utilizadas

- **PHP** (puro)
- **JavaScript**
- **jQuery**
- **Ajax**
- **HTML/CSS**
- **Banco de Dados MySQL (ou outro, conforme configuração)**

## 🎯 Funcionalidades

- Cadastro de novos usuários
- Edição de dados existentes
- Remoção de usuários
- Listagem dinâmica de usuários (renderizada via Ajax)
- Validação de campos obrigatórios no front-end
- Máscaras para e-mail e telefone

## 📁 Estrutura MVC

O projeto está dividido em três camadas principais:

- **Model**: Camada responsável pela lógica de acesso aos dados.
- **View**: Interface do usuário (HTML + JS + jQuery).
- **Controller**: Camada intermediária que trata as requisições e conecta a View ao Model.
